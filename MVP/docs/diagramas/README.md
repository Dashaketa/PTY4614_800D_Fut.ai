# Diagramas históricos

[flujo-futai-historico.html](flujo-futai-historico.html) conserva el documento visual que antes estaba en `MVP/FrontEnd/Flujo FUT.AI.html`.

Es una referencia histórica de planificación: contiene propuestas de servicios cloud y etapas que no corresponden necesariamente al MVP implementado. Para conocer el comportamiento vigente, consultar [arquitectura.md](../arquitectura.md).

Los diagramas nuevos deben identificar la fecha y distinguir implementación actual de propuestas. Capturas pequeñas y revisadas pueden guardarse aquí o en `docs/imagenes/`; las salidas de cada procesamiento permanecen fuera de Git.
